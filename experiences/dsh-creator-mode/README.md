# DSH 创造模式与插件提示词

本目录收录 DeepSeek Harness（dsh）里“用对话做插件”的经验：官方提示词原文、通用提示词模板、入口位置、生成物验收和常见偏差。

和本库其他主题一样按“症状驱动”组织：**什么现象 → 先看什么 → 为什么这样写 → 怎么用 → 怎么验收**。

> 证据边界：本主题基于官方公开页面和本机 dsh 0.2.1-rc.3 的界面文案/包文档核对整理，没有逐条复现视频效果；官方提示词逐字收录，清单契约和模板是通用设计，首次使用需要按自己的模型项目填数据并验收。

## 使用前先确认

1. 合集版本：官方合集当前是“七个 Demo”，没有单独叫“模型架构示意图”的条目；通用做法见条目里的清单契约。
2. dsh 版本：创造模式对应 preset `cordis`，菜单文案会随版本变化，以“能否进入创造模式”为准。
3. 平台：官方提示词里的 macOS 窗口按钮约束只对 macOS 客户端有意义。

新增条目请按 [CONTRIBUTING.md](../../CONTRIBUTING.md) 操作，并运行 `python3 toolbox/build_catalog.py`。
