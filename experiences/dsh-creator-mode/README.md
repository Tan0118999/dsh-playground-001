# DSH 创造模式与插件提示词

本目录收录 DeepSeek Harness（dsh）里“用对话做插件”的经验：官方提示词原文、入口位置、生成物验收和常见偏差。条目不多，但每条都尽量给出可复制的提示词和可观察的验收点。

和本库其他主题一样按“症状驱动”组织：**什么现象 → 先看什么 → 为什么这样写 → 怎么用 → 怎么验收**。

> 证据边界：本主题基于官方公开页面和本机 dsh 0.2.1-rc.3 的界面文案/包文档核对整理，没有逐条复现视频效果；官方提示词逐字收录，改写示例会明确标注“未实测”。

## 使用前先确认

1. 合集版本：官方合集当前是“七个 Demo”，没有单独叫“模型架构示意图”的条目。
2. dsh 版本：创造模式对应 preset `cordis`，菜单文案会随版本变化，以“能否进入创造模式”为准。
3. 平台：官方提示词里的 macOS 窗口按钮约束只对 macOS 客户端有意义。

新增条目请按 [CONTRIBUTING.md](../../CONTRIBUTING.md) 操作，并运行 `python3 toolbox/build_catalog.py`。
